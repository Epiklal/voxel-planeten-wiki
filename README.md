# Voxel-Planeten-Wiki

Blockspiel im echten Sonnensystem: runde Planeten und Monde in echter Größe und echtem Abstand, nahtlos vom Boden ins All und zum nächsten Himmelskörper.

Dieses Wiki wird aus den Daten des Spiels erzeugt – was hier steht, gilt genau so im Spiel. Im Spiel öffnet man es im Hauptmenü oder im Pausemenü (Knopf „Wiki“).
