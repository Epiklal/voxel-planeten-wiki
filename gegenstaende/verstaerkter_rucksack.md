# Verstärkter Rucksack

![Verstärkter Rucksack](../bilder/gegenstaende/verstaerkter_rucksack.png)

| Eigenschaft | Wert |
|---|---|
|  | 2 Reihen mehr im Inventar |
|  | Gehört auf den Rucksack-Platz (Shift-Klick zieht ihn an) |
|  | Ausziehen geht nur, wenn seine Reihen leer sind |
|  | An der Werkbank aufrüsten |

## Herstellen

- 1 × [Stoffrucksack](../gegenstaende/stoffrucksack.md) + 4 × [Gummi](../gegenstaende/gummi.md) + 4 × [Eisenplatte](../gegenstaende/eisenplatte.md) + 8 × [Schrauben](../gegenstaende/schrauben.md) → 1 × [Verstärkter Rucksack](../gegenstaende/verstaerkter_rucksack.md) (Werkbank, 8 s)

## Verwendet für

[Hightech-Rucksack](../gegenstaende/hightech_rucksack.md)
