# Bio-Filter

![Bio-Filter](../bilder/gegenstaende/bio_filter.png)

| Eigenschaft | Wert |
|---|---|
| Hunger und Durst kommen | 25 % langsamer |
|  | Einsetzen an einer Implantatstation mit Strom |
| Ab Stufe | 8 |
|  | Bleibt auch nach dem Tod |
| Braucht Energie | 5 % mehr Hunger und Durst |
|  | Fällt im Sonnensturm ohne Deckung aus |

## Herstellen

- 2 × [Titanplatte](../gegenstaende/titanplatte.md) + 4 × [Graphen](../gegenstaende/graphen.md) + 2 × [Kohlenstoff-Nanoröhren](../gegenstaende/kohlenstoff_nanoroehren.md) + 2 × [Siliziumwafer](../gegenstaende/siliziumwafer.md) → 1 × [Bio-Filter](../gegenstaende/bio_filter.md) (Werkbank, 40 s)
