# Stapelimplantat

![Stapelimplantat](../bilder/gegenstaende/stapelimplantat.png)

| Eigenschaft | Wert |
|---|---|
|  | Stapel im Inventar noch einmal doppelt so groß, für immer |
|  | Einsetzen an einer Implantatstation mit Strom |
|  | Geht einmal |
|  | Bleibt auch nach dem Tod |

## Herstellen

- 4 × [Siliziumwafer](../gegenstaende/siliziumwafer.md) + 2 × [Galliumarsenid](../gegenstaende/galliumarsenid.md) + 1 × [YBCO-Supraleiter](../gegenstaende/ybco_supraleiter.md) + 2 × [Titanplatte](../gegenstaende/titanplatte.md) → 1 × [Stapelimplantat](../gegenstaende/stapelimplantat.md) (Werkbank, 40 s)
