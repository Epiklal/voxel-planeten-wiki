# Panzerhaut-Implantat

![Panzerhaut-Implantat](../bilder/gegenstaende/panzerhaut_implantat.png)

| Eigenschaft | Wert |
|---|---|
|  | 20 Lebenspunkte mehr, für immer |
|  | Einsetzen an einer Implantatstation mit Strom |
| Geht dreimal | ab Stufe 3, 6 und 10 |
|  | Bleibt auch nach dem Tod |
| Braucht Energie | 5 % mehr Hunger und Durst |
|  | Im Sonnensturm ohne Deckung tun Implantate weh |

## Herstellen

- 4 × [Titanplatte](../gegenstaende/titanplatte.md) + 2 × [Kohlenstoff-Nanoröhren](../gegenstaende/kohlenstoff_nanoroehren.md) + 1 × [Siliziumwafer](../gegenstaende/siliziumwafer.md) → 1 × [Panzerhaut-Implantat](../gegenstaende/panzerhaut_implantat.md) (Werkbank, 30 s)
