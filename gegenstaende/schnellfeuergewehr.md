# Schnellfeuergewehr

![Schnellfeuergewehr](../bilder/gegenstaende/schnellfeuergewehr.png)

| Eigenschaft | Wert |
|---|---|
| Magazin | 30 Schuss |
| Schaden | 4 · Reichweite 100 m |
|  | 667 Schuss pro Minute · Nachladen 2,2 s |
|  | Dauerfeuer |
| Rechte Maustaste | zielen · R: nachladen |

## Herstellen

- 3 × [Verstärkte Eisenplatte](../gegenstaende/verstaerkte_eisenplatte.md) + 3 × [Eisenstange](../gegenstaende/eisenstange.md) + 1 × [Rotor](../gegenstaende/rotor.md) + 8 × [Schrauben](../gegenstaende/schrauben.md) → 1 × [Schnellfeuergewehr](../gegenstaende/schnellfeuergewehr.md) (Werkbank, 20 s)
