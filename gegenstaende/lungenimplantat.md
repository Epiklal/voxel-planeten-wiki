# Lungenimplantat

![Lungenimplantat](../bilder/gegenstaende/lungenimplantat.png)

| Eigenschaft | Wert |
|---|---|
|  | Du hältst die Luft doppelt so lange an |
|  | Einsetzen an einer Implantatstation mit Strom |
| Ab Stufe | 4 |
|  | Bleibt auch nach dem Tod |
| Braucht Energie | 5 % mehr Hunger und Durst |
|  | Fällt im Sonnensturm ohne Deckung aus |

## Herstellen

- 2 × [Titanplatte](../gegenstaende/titanplatte.md) + 2 × [Graphen](../gegenstaende/graphen.md) + 2 × [Siliziumwafer](../gegenstaende/siliziumwafer.md) + 1 × [Lithium-Ionen-Zelle](../gegenstaende/lithium_ionen_zelle.md) → 1 × [Lungenimplantat](../gegenstaende/lungenimplantat.md) (Werkbank, 30 s)
