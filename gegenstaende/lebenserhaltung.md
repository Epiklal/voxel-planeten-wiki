# Lebenserhaltung

![Lebenserhaltung](../bilder/gegenstaende/lebenserhaltung.png)

Auf der ISS kommen rund 98 % des Wassers zurück – auch aus Schweiß und Urin.

| Eigenschaft | Wert |
|---|---|
|  | Füllt den geschlossenen Raum, in dem sie steht, mit Atemluft |
| Reicht für | 2000 m³, größere Räume brauchen mehrere |
| Braucht | 50 kW am Stromnetz |
|  | Nur, wo draußen keine Atemluft ist (Mond, Mars, Weltall) |
|  | Dicht halten Gestein, Metall, Glas, Beton und Eisentüren |
|  | Holz, Erde, Sand, Regolith, Wolle und Holztüren lassen Luft durch |

## Herstellen

- 6 × [Eisenplatte](../gegenstaende/eisenplatte.md) + 2 × [Rotor](../gegenstaende/rotor.md) + 2 × [Aluminiumblech](../gegenstaende/aluminiumblech.md) + 1 × [Glas](../bloecke/glas.md) + 12 × [Kupferdraht](../gegenstaende/kupferdraht.md) → 1 × [Lebenserhaltung](../gegenstaende/lebenserhaltung.md) (Werkbank, 20 s)
