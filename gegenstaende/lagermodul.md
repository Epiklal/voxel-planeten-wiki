# Lagermodul

![Lagermodul](../bilder/gegenstaende/lagermodul.png)

| Eigenschaft | Wert |
|---|---|
|  | Eine Reihe mehr im Inventar, für immer |
|  | Zum Einsetzen rechte Maustaste gedrückt halten |
|  | Geht einmal |
|  | Bleibt auch nach dem Tod |

## Herstellen

- 2 × [Kiste](../gegenstaende/kiste.md) + 1 × [Modularer Rahmen](../gegenstaende/modularer_rahmen.md) + 4 × [Eisenplatte](../gegenstaende/eisenplatte.md) + 8 × [Kupferdraht](../gegenstaende/kupferdraht.md) → 1 × [Lagermodul](../gegenstaende/lagermodul.md) (Werkbank, 15 s)
