# Lagerimplantat

![Lagerimplantat](../bilder/gegenstaende/lagerimplantat.png)

| Eigenschaft | Wert |
|---|---|
|  | Eine Reihe mehr im Inventar, für immer |
|  | Einsetzen an einer Implantatstation mit Strom |
|  | Geht zweimal |
|  | Bleibt auch nach dem Tod |

## Herstellen

- 2 × [Siliziumwafer](../gegenstaende/siliziumwafer.md) + 2 × [Graphen](../gegenstaende/graphen.md) + 2 × [Titanplatte](../gegenstaende/titanplatte.md) + 1 × [Lithium-Ionen-Zelle](../gegenstaende/lithium_ionen_zelle.md) → 1 × [Lagerimplantat](../gegenstaende/lagerimplantat.md) (Werkbank, 30 s)
