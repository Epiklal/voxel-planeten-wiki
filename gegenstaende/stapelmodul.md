# Stapelmodul

![Stapelmodul](../bilder/gegenstaende/stapelmodul.png)

| Eigenschaft | Wert |
|---|---|
|  | Doppelt so große Stapel im Inventar, für immer |
|  | Zum Einsetzen rechte Maustaste gedrückt halten |
|  | Geht einmal |
|  | Bleibt auch nach dem Tod |

## Herstellen

- 2 × [Verstärkte Eisenplatte](../gegenstaende/verstaerkte_eisenplatte.md) + 4 × [Quarzkristall](../gegenstaende/quarzkristall.md) + 1 × [Akku](../gegenstaende/akku.md) + 8 × [Kupferdraht](../gegenstaende/kupferdraht.md) → 1 × [Stapelmodul](../gegenstaende/stapelmodul.md) (Werkbank, 15 s)
