# Stoffrucksack

![Stoffrucksack](../bilder/gegenstaende/stoffrucksack.png)

| Eigenschaft | Wert |
|---|---|
|  | Eine Reihe mehr im Inventar |
|  | Gehört auf den Rucksack-Platz (Shift-Klick zieht ihn an) |
|  | Ausziehen geht nur, wenn seine Reihen leer sind |
|  | An der Werkbank aufrüsten |

## Herstellen

- 6 × [Leder](../gegenstaende/leder.md) + 4 × [Faden](../gegenstaende/faden.md) + 1 × [Eisenstange](../gegenstaende/eisenstange.md) → 1 × [Stoffrucksack](../gegenstaende/stoffrucksack.md) (Werkbank, 4 s)

## Verwendet für

[Verstärkter Rucksack](../gegenstaende/verstaerkter_rucksack.md)
