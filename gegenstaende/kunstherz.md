# Kunstherz

![Kunstherz](../bilder/gegenstaende/kunstherz.png)

| Eigenschaft | Wert |
|---|---|
|  | Du heilst doppelt so schnell |
|  | Einsetzen an einer Implantatstation mit Strom |
| Ab Stufe | 5 |
|  | Bleibt auch nach dem Tod |
| Braucht Energie | 5 % mehr Hunger und Durst |
|  | Fällt im Sonnensturm ohne Deckung aus |

## Herstellen

- 2 × [Titanplatte](../gegenstaende/titanplatte.md) + 4 × [Siliziumwafer](../gegenstaende/siliziumwafer.md) + 2 × [Lithium-Ionen-Zelle](../gegenstaende/lithium_ionen_zelle.md) + 1 × [Galliumarsenid](../gegenstaende/galliumarsenid.md) → 1 × [Kunstherz](../gegenstaende/kunstherz.md) (Werkbank, 40 s)
