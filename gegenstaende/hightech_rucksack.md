# Hightech-Rucksack

![Hightech-Rucksack](../bilder/gegenstaende/hightech_rucksack.png)

| Eigenschaft | Wert |
|---|---|
|  | 3 Reihen mehr im Inventar |
|  | Gehört auf den Rucksack-Platz (Shift-Klick zieht ihn an) |
|  | Ausziehen geht nur, wenn seine Reihen leer sind |

## Herstellen

- 1 × [Verstärkter Rucksack](../gegenstaende/verstaerkter_rucksack.md) + 4 × [Kohlefaserplatte](../gegenstaende/kohlefaserplatte.md) + 4 × [Aluminiumblech](../gegenstaende/aluminiumblech.md) + 2 × [Kohlenstoff-Nanoröhren](../gegenstaende/kohlenstoff_nanoroehren.md) → 1 × [Hightech-Rucksack](../gegenstaende/hightech_rucksack.md) (Werkbank, 15 s)
