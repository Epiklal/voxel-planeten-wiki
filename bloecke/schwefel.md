# Schwefel

![Schwefel](../bilder/bloecke/schwefel.png)

Brennt mit blauer Flamme. Die Vulkane auf dem Jupitermond Io spucken Schwefel.

| Eigenschaft | Wert |
|---|---|
| Symbol | S |
| Ordnungszahl | 16 |
| Gruppe | Nichtmetall |
| Zustand (20 °C) | fest |
| Dichte | 2,07 g/cm³ |
| Schmilzt bei | 115 °C |
| Härte (Mohs) | 2 |
| Radioaktiv | nein, stabil |
| Art | fester Block |
| Abbauen | 1,2 s |
| Vorkommen | Io |
| Gibt es auf | [Io](../himmelskoerper/io.md) |
