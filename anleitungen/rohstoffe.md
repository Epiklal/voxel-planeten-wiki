# Rohstoffe

Erzadern im Gestein, die Tiefe zählt ab Meeresspiegel (Grundgestein bei −128):

| Himmelskörper     | Rohstoffe                                                                                                                                                                                                                                                                                        |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Erde              | Kohle (bis 160 m Höhe), Eisen, Kupfer, Kalkstein (große Nester), Bauxit (nahe der Oberfläche), Quarz (unter 0), Schwefel (unter −30), Gold (unter −40), Uran (unter −80, selten), Diamanten (unter −100, sehr selten, nur mit der Eisenspitzhacke), Ölschiefer (große Lager zwischen −90 und 20) |
| Mond              | viel Titanerz (Ilmenit), helles Anorthosit des Hochlands (große Nester, Aluminium), Eisen, Quarz, wenig Uran – keine Kohle                                                                                                                                                                       |
| Mars              | sehr viel Eisen, Hämatit (doppelt so ergiebig), Schwefel, Quarz, Kupfer, Bauxit, etwas Gold und Uran                                                                                                                                                                                             |
| Merkur            | viel Graphit (Merkurs dunkle Kruste ist kohlenstoffreich), Eisen, Titanerz, Schwefel, Quarz, Kupfer, etwas Gold und Uran                                                                                                                                                                         |
| Venus             | Venus-Metallfrost (auf den Bergen, 2–3,5 m tief), Eisen, Titanerz, Schwefel, Quarz, Kupfer, etwas Gold und Uran                                                                                                                                                                                  |
| Io, Gesteinsmonde | Eisen, Titanerz, Schwefel, Quarz, Kupfer, etwas Gold und Uran                                                                                                                                                                                                                                    |
| Eismonde, Ceres   | fast nur Eis, Salz (aus dem Ozean unter dem Eis), Methaneis, wenig Quarz und Eisen                                                                                                                                                                                                               |
| Gasriesen         | keine Erze – aber ihre Wolken (Jupiter braun, Saturn goldgelb, Uranus türkis, Neptun blau) kann man mit dem Schiff abbauen                                                                                                                                                                       |

Was man aus den Blöcken der anderen Himmelskörper macht (im Inventar zeigt der
Tooltip, wo es einen Rohstoff gibt und was der Ofen daraus macht):

| Rohstoff (wo)                          | wird zu                                                                                                                   |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Ilmenit (Mond, Merkur …)               | Titanbarren (Ofen) → Titanplatten, Titanrüstung, Titanspitzhacke und -axt, Titanblock, leichteres Jetpack                 |
| Bauxit (Erde, Mars), Anorthosit (Mond) | Aluminiumbarren (Ofen) → Aluminiumblech, Hochspannungskabel (wie echte Freileitungen), Solarmodule, Akkus, Aluminiumblock |
| Hämatit (Mars)                         | 2 Eisenbarren (Ofen)                                                                                                      |
| Graphit (Merkur)                       | Kohlefaserplatten (3 Graphit → 2, ergiebiger als Kohle)                                                                   |
| Tholin (Titan, Pluto)                  | Kunststoff (Ofen) → isolierte Kupferkabel statt mit Gummi                                                                 |
| Schwefel (Io), Salz (Eismonde)         | Akkus (statt Schwefelerz)                                                                                                 |
| Regolith, dunkler Regolith (Mond …)    | Regolithziegel (Ofen, gesintert – so will man in echt auf dem Mond bauen)                                                 |
| Roter Sand (Mars)                      | Marsziegel (Ofen)                                                                                                         |
| Basalt (Merkur, Venus, Io)             | Basaltplatten                                                                                                             |
| Eis (Eismonde, Polkappen)              | Wasser (Ofen) – auch zum Ausgießen auf dem Mars –, Packeis                                                                |
