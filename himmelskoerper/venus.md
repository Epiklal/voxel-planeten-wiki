# Venus

Heißer als Merkur (465 °C), obwohl doppelt so weit von der Sonne: Der Treibhauseffekt. Sie dreht sich rückwärts, ihr Tag ist länger als ihr Jahr – und auf den Bergen liegt Schnee aus Metall.

| Eigenschaft | Wert |
|---|---|
| Art | Planet |
| Radius | 6052 km |
| Masse | 4,87 · 10^24 kg |
| Schwerkraft | 0,904 g (8,87 m/s²) |
| Sprunghöhe | 1,38 m |
| Ein Tag | 117 Tage |
| Umlauf um die Sonne (ein Jahr) | 225 Tage |
| Abstand zur Sonne | 0,723 AE (108 Mio. km) |
| Exzentrizität | 0,007 |
| Atmosphäre | bis 250 km hoch, nicht atembar (Raumanzug) |
