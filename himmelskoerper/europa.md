# Europa

Unter dem Eis liegt ein Ozean mit mehr Wasser als alle Meere der Erde zusammen – einer der besten Orte für die Suche nach Leben.

| Eigenschaft | Wert |
|---|---|
| Art | Mond von [Jupiter](../himmelskoerper/jupiter.md) |
| Radius | 1561 km |
| Masse | 4,8 · 10^22 kg |
| Schwerkraft | 0,134 g (1,31 m/s²) |
| Sprunghöhe | 9,34 m |
| Ein Tag | 3,53 Tage |
| Umlauf | 3,53 Tage |
| Abstand zu Jupiter | 671 100 km |
| Exzentrizität | 0,009 |
| Richtung | vorwärts |
| Gebundene Rotation | zeigt seinem Planeten immer dieselbe Seite |
| Atmosphäre | keine (Raumanzug) |
| Strahlung am Boden | 13,9 Sv/h |
| Oberfläche | [Eis](../bloecke/eis.md), [Schmutziges Eis](../bloecke/schmutziges_eis.md) |
