# Kallisto

Die am dichtesten mit Kratern übersäte Oberfläche im Sonnensystem: Seit über 4 Milliarden Jahren hat sich hier kaum etwas verändert.

| Eigenschaft | Wert |
|---|---|
| Art | Mond von [Jupiter](../himmelskoerper/jupiter.md) |
| Radius | 2410 km |
| Masse | 1,08 · 10^23 kg |
| Schwerkraft | 0,126 g (1,24 m/s²) |
| Sprunghöhe | 9,93 m |
| Ein Tag | 16,8 Tage |
| Umlauf | 16,7 Tage |
| Abstand zu Jupiter | 1 882 700 km |
| Exzentrizität | 0,007 |
| Richtung | vorwärts |
| Gebundene Rotation | zeigt seinem Planeten immer dieselbe Seite |
| Atmosphäre | keine (Raumanzug) |
| Strahlung am Boden | 729 mSv/h |
| Oberfläche | [Dunkler Regolith](../bloecke/dunkler_regolith.md), [Schmutziges Eis](../bloecke/schmutziges_eis.md), [Graues Eis](../bloecke/graues_eis.md) |
