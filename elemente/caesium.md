# Caesium

![Caesium](../bilder/elemente/caesium.png)

Schmilzt bei 28 °C und explodiert in Wasser. Die Sekunde ist über Caesium festgelegt: 9 192 631 770 Schwingungen.

| Eigenschaft | Wert |
|---|---|
| Symbol | Cs |
| Ordnungszahl | 55 |
| Gruppe | Alkalimetall |
| Zustand (20 °C) | fest |
| Dichte | 1,93 g/cm³ |
| Schmilzt bei | 28 °C |
| Härte (Mohs) | 0,2 |
| Radioaktiv | nein, stabil |
| Ausrüstung daraus | nein |
| Im Wasser | explodiert |

## Im Wasser

2 Cs + 2 H2O → 2 CsOH + H2: Caesium explodiert schon beim Berühren, heftiger als alle anderen Metalle, die man je in der Hand hatte.

## Herstellen

- 8 × [Lepidolith](../bloecke/lepidolith.md) + 1 × [Salzsäure](../gegenstaende/salzsaeure.md) → 1 × [Caesium](../elemente/caesium.md) (Elektrolyseanlage, 30 s)
