# Fluor

![Fluor](../bilder/elemente/fluor.png)

Das reaktivste Element überhaupt – es greift Glas an und bringt sogar Wasser zum Brennen.

| Eigenschaft | Wert |
|---|---|
| Symbol | F |
| Ordnungszahl | 9 |
| Gruppe | Halogen |
| Zustand (20 °C) | Gas |
| Dichte | 0,002 g/cm³ |
| Schmilzt bei | −220 °C |
| Radioaktiv | nein, stabil |

## Herstellen

- 2 × [Flusssäure](../gegenstaende/flusssaeure.md) → 1 × [Fluor](../elemente/fluor.md) (Elektrolyseanlage, 10 s)

## Verwendet für

[Uranhexafluorid](../gegenstaende/uranhexafluorid.md)
