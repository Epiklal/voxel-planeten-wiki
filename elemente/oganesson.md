# Oganesson

![Oganesson](../bilder/elemente/oganesson.png)

Das schwerste Element überhaupt, nach dem lebenden Forscher Juri Oganessjan. Bisher wurden nur fünf Atome nachgewiesen.

| Eigenschaft | Wert |
|---|---|
| Symbol | Og |
| Ordnungszahl | 118 |
| Gruppe | Edelgas |
| Zustand (20 °C) | fest |
| Dichte | 7,2 g/cm³ |
| Schmilzt bei | 52 °C |
| Radioaktiv | ja, Halbwertszeit 0,7 ms |

## Herstellen

- 1 × [Californium](../elemente/californium.md) + 8 × [Calcium](../elemente/calcium.md) → 1 × [Oganesson](../elemente/oganesson.md) (Teilchenbeschleuniger, 960 s)
