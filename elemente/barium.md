# Barium

![Barium](../bilder/elemente/barium.png)

Bariumbrei macht den Darm im Röntgenbild sichtbar; im Feuerwerk leuchtet Barium grün.

| Eigenschaft | Wert |
|---|---|
| Symbol | Ba |
| Ordnungszahl | 56 |
| Gruppe | Erdalkalimetall |
| Zustand (20 °C) | fest |
| Dichte | 3,51 g/cm³ |
| Schmilzt bei | 727 °C |
| Härte (Mohs) | 1,2 |
| Radioaktiv | nein, stabil |
| Ausrüstung daraus | ja |
| Im Wasser | sprudelt |

## Im Wasser

Ba + 2 H2O → Ba(OH)2 + H2: Barium sprudelt sehr heftig – im Feuerwerk färbt es grün.

## Herstellen

- 2 × [Baryt](../bloecke/baryt.md) + 1 × [Aluminiumbarren](../elemente/aluminiumbarren.md) → 1 × [Barium](../elemente/barium.md) (Induktionsofen, 12 s)
