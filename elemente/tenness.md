# Tenness

![Tenness](../bilder/elemente/tenness.png)

Nach Tennessee. Eigentlich ein Halogen – benimmt sich aber wohl eher wie ein Metall.

| Eigenschaft | Wert |
|---|---|
| Symbol | Ts |
| Ordnungszahl | 117 |
| Gruppe | Halogen |
| Zustand (20 °C) | fest |
| Dichte | 7,2 g/cm³ |
| Schmilzt bei | 427 °C |
| Radioaktiv | ja, Halbwertszeit 51 ms |

## Herstellen

- 1 × [Berkelium](../elemente/berkelium.md) + 8 × [Calcium](../elemente/calcium.md) → 1 × [Tenness](../elemente/tenness.md) (Teilchenbeschleuniger, 900 s)
