# Quecksilber

![Quecksilber](../bilder/elemente/quecksilber.png)

Das einzige Metall, das bei Zimmertemperatur flüssig ist. Hutmacher wurden davon krank ("verrückt wie ein Hutmacher").

| Eigenschaft | Wert |
|---|---|
| Symbol | Hg |
| Ordnungszahl | 80 |
| Gruppe | Übergangsmetall |
| Zustand (20 °C) | flüssig |
| Dichte | 13,534 g/cm³ |
| Schmilzt bei | −39 °C |
| Radioaktiv | nein, stabil |
| Ausrüstung daraus | nein |

## Herstellen

- 1 × [Zinnober](../bloecke/zinnober.md) → 1 × [Quecksilber](../elemente/quecksilber.md) (Ofen, 6 s)
