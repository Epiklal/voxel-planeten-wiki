# Darmstadtium

![Darmstadtium](../bilder/elemente/darmstadtium.png)

Nach Darmstadt, wo es 1994 zum ersten Mal entstand.

| Eigenschaft | Wert |
|---|---|
| Symbol | Ds |
| Ordnungszahl | 110 |
| Gruppe | Übergangsmetall |
| Zustand (20 °C) | fest |
| Dichte | 34,8 g/cm³ |
| Schmilzt bei | −273 °C |
| Radioaktiv | ja, Halbwertszeit 12,7 s |
| Ausrüstung daraus | nein |

## Herstellen

- 1 × [Blei](../elemente/blei.md) + 8 × [Nickel](../elemente/nickel.md) → 1 × [Darmstadtium](../elemente/darmstadtium.md) (Teilchenbeschleuniger, 540 s)
