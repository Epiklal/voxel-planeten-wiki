# Promethium

![Promethium](../bilder/elemente/promethium.png)

Es gibt fast keins: in der ganzen Erdkruste vielleicht ein halbes Kilogramm. Leuchtfarbe auf alten Uhren.

| Eigenschaft | Wert |
|---|---|
| Symbol | Pm |
| Ordnungszahl | 61 |
| Gruppe | Lanthanoid |
| Zustand (20 °C) | fest |
| Dichte | 7,26 g/cm³ |
| Schmilzt bei | 1042 °C |
| Härte (Mohs) | 3 |
| Radioaktiv | ja, Halbwertszeit 17,7 Jahre |
| Ausrüstung daraus | ja |

## Herstellen

- 4 × [Uran](../elemente/uran.md) + 1 × [Uranbrennstab](../gegenstaende/uranbrennstab.md) → 1 × [Promethium](../elemente/promethium.md) (Forschungsreaktor, 60 s)

- ![](../bilder/gegenstaende/promethiumharnisch.png) [Promethiumharnisch](../gegenstaende/promethiumharnisch.md): 8 × Promethium
