# Dysprosium

![Dysprosium](../bilder/elemente/dysprosium.png)

Hält Neodym-Magnete auch heiß stark – in jedem Elektroauto.

| Eigenschaft | Wert |
|---|---|
| Symbol | Dy |
| Ordnungszahl | 66 |
| Gruppe | Lanthanoid |
| Zustand (20 °C) | fest |
| Dichte | 8,54 g/cm³ |
| Schmilzt bei | 1407 °C |
| Härte (Mohs) | 3 |
| Radioaktiv | nein, stabil |
| Ausrüstung daraus | ja |

## Herstellen

- 3 × [Seltenerd-Konzentrat](../gegenstaende/seltenerd_konzentrat.md) → 1 × [Dysprosium](../elemente/dysprosium.md) (Trennanlage, 19 s)
