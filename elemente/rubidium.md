# Rubidium

![Rubidium](../bilder/elemente/rubidium.png)

Schmilzt bei 39 °C und entzündet sich an der Luft. Rubidium-Atomuhren fliegen in GPS-Satelliten.

| Eigenschaft | Wert |
|---|---|
| Symbol | Rb |
| Ordnungszahl | 37 |
| Gruppe | Alkalimetall |
| Zustand (20 °C) | fest |
| Dichte | 1,532 g/cm³ |
| Schmilzt bei | 39 °C |
| Härte (Mohs) | 0,3 |
| Radioaktiv | nein, stabil |
| Ausrüstung daraus | nein |
| Im Wasser | explodiert |

## Im Wasser

2 Rb + 2 H2O → 2 RbOH + H2: Rubidium ist schwerer als Wasser, sinkt – und explodiert.

## Herstellen

- 4 × [Lepidolith](../bloecke/lepidolith.md) + 1 × [Salzsäure](../gegenstaende/salzsaeure.md) → 1 × [Rubidium](../elemente/rubidium.md) (Elektrolyseanlage, 20 s)
