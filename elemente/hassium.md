# Hassium

![Hassium](../bilder/elemente/hassium.png)

Nach Hessen (lateinisch Hassia) – entdeckt in Darmstadt.

| Eigenschaft | Wert |
|---|---|
| Symbol | Hs |
| Ordnungszahl | 108 |
| Gruppe | Übergangsmetall |
| Zustand (20 °C) | fest |
| Dichte | 41 g/cm³ |
| Schmilzt bei | −273 °C |
| Radioaktiv | ja, Halbwertszeit 16 s |
| Ausrüstung daraus | nein |

## Herstellen

- 1 × [Blei](../elemente/blei.md) + 8 × [Eisenbarren](../elemente/eisenbarren.md) → 1 × [Hassium](../elemente/hassium.md) (Teilchenbeschleuniger, 480 s)
