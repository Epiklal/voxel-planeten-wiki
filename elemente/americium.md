# Americium

![Americium](../bilder/elemente/americium.png)

Steckt in fast jedem Rauchmelder – ein winziges Stückchen.

| Eigenschaft | Wert |
|---|---|
| Symbol | Am |
| Ordnungszahl | 95 |
| Gruppe | Actinoid |
| Zustand (20 °C) | fest |
| Dichte | 12 g/cm³ |
| Schmilzt bei | 1176 °C |
| Härte (Mohs) | 3 |
| Radioaktiv | ja, Halbwertszeit 7370 Jahre |
| Ausrüstung daraus | ja |

## Herstellen

- 2 × [Plutonium](../elemente/plutonium.md) + 1 × [Uranbrennstab](../gegenstaende/uranbrennstab.md) → 1 × [Americium](../elemente/americium.md) (Forschungsreaktor, 120 s)
