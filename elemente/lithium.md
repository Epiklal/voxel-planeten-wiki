# Lithium

![Lithium](../bilder/elemente/lithium.png)

Das leichteste Metall – es schwimmt auf Wasser (und reagiert dabei). Steckt in fast jedem Akku.

| Eigenschaft | Wert |
|---|---|
| Symbol | Li |
| Ordnungszahl | 3 |
| Gruppe | Alkalimetall |
| Zustand (20 °C) | fest |
| Dichte | 0,534 g/cm³ |
| Schmilzt bei | 181 °C |
| Härte (Mohs) | 0,6 |
| Radioaktiv | nein, stabil |
| Ausrüstung daraus | ja |
| Im Wasser | sprudelt |

## Im Wasser

2 Li + 2 H2O → 2 LiOH + H2: Lithium schwimmt (halb so dicht wie Wasser) und sprudelt ruhig – Wasserstoff entweicht.

## Herstellen

- 2 × [Spodumen](../bloecke/spodumen.md) + 1 × [Salzsäure](../gegenstaende/salzsaeure.md) → 1 × [Lithium](../elemente/lithium.md) (Elektrolyseanlage, 12 s)
