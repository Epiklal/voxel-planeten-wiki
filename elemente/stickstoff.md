# Stickstoff

![Stickstoff](../bilder/elemente/stickstoff.png)

78 % der Luft – flüssig ist er −196 °C kalt.

| Eigenschaft | Wert |
|---|---|
| Symbol | N |
| Ordnungszahl | 7 |
| Gruppe | Nichtmetall |
| Zustand (20 °C) | Gas |
| Dichte | 0,001 g/cm³ |
| Schmilzt bei | −210 °C |
| Radioaktiv | nein, stabil |
