# Antimon

![Antimon](../bilder/elemente/antimon.png)

Die alten Ägypter malten sich damit die Augen schwarz.

| Eigenschaft | Wert |
|---|---|
| Symbol | Sb |
| Ordnungszahl | 51 |
| Gruppe | Halbmetall |
| Zustand (20 °C) | fest |
| Dichte | 6,697 g/cm³ |
| Schmilzt bei | 631 °C |
| Härte (Mohs) | 3 |
| Radioaktiv | nein, stabil |
