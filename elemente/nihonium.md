# Nihonium

![Nihonium](../bilder/elemente/nihonium.png)

Das erste Element aus Asien ("Nihon" = Japan). Für drei Atome liefen die Versuche neun Jahre.

| Eigenschaft | Wert |
|---|---|
| Symbol | Nh |
| Ordnungszahl | 113 |
| Gruppe | Metall |
| Zustand (20 °C) | fest |
| Dichte | 16 g/cm³ |
| Schmilzt bei | 427 °C |
| Radioaktiv | ja, Halbwertszeit 9,5 s |
| Ausrüstung daraus | nein |

## Herstellen

- 1 × [Bismut](../elemente/bismut.md) + 8 × [Zink](../elemente/zink.md) → 1 × [Nihonium](../elemente/nihonium.md) (Teilchenbeschleuniger, 660 s)
