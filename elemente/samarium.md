# Samarium

![Samarium](../bilder/elemente/samarium.png)

Samarium-Cobalt-Magnete halten auch bei 300 °C.

| Eigenschaft | Wert |
|---|---|
| Symbol | Sm |
| Ordnungszahl | 62 |
| Gruppe | Lanthanoid |
| Zustand (20 °C) | fest |
| Dichte | 7,52 g/cm³ |
| Schmilzt bei | 1072 °C |
| Härte (Mohs) | 3 |
| Radioaktiv | nein, stabil |
| Ausrüstung daraus | ja |

## Herstellen

- 2 × [Seltenerd-Konzentrat](../gegenstaende/seltenerd_konzentrat.md) → 1 × [Samarium](../elemente/samarium.md) (Trennanlage, 16 s)
