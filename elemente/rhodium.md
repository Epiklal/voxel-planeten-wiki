# Rhodium

![Rhodium](../bilder/elemente/rhodium.png)

Eines der teuersten Metalle der Welt – in jedem Auto-Katalysator.

| Eigenschaft | Wert |
|---|---|
| Symbol | Rh |
| Ordnungszahl | 45 |
| Gruppe | Übergangsmetall |
| Zustand (20 °C) | fest |
| Dichte | 12,41 g/cm³ |
| Schmilzt bei | 1964 °C |
| Härte (Mohs) | 6 |
| Radioaktiv | nein, stabil |
| Ausrüstung daraus | ja |

## Herstellen

- 3 × [Platinmetall-Konzentrat](../gegenstaende/platinmetall_konzentrat.md) → 1 × [Rhodium](../elemente/rhodium.md) (Trennanlage, 25 s)
