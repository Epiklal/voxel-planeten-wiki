# Moscovium

![Moscovium](../bilder/elemente/moscovium.png)

Nach der Region Moskau.

| Eigenschaft | Wert |
|---|---|
| Symbol | Mc |
| Ordnungszahl | 115 |
| Gruppe | Metall |
| Zustand (20 °C) | fest |
| Dichte | 13,5 g/cm³ |
| Schmilzt bei | 397 °C |
| Radioaktiv | ja, Halbwertszeit 650 ms |
| Ausrüstung daraus | nein |

## Herstellen

- 1 × [Americium](../elemente/americium.md) + 8 × [Calcium](../elemente/calcium.md) → 1 × [Moscovium](../elemente/moscovium.md) (Teilchenbeschleuniger, 780 s)
