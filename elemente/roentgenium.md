# Roentgenium

![Roentgenium](../bilder/elemente/roentgenium.png)

Nach Wilhelm Conrad Röntgen.

| Eigenschaft | Wert |
|---|---|
| Symbol | Rg |
| Ordnungszahl | 111 |
| Gruppe | Übergangsmetall |
| Zustand (20 °C) | fest |
| Dichte | 28,7 g/cm³ |
| Schmilzt bei | −273 °C |
| Radioaktiv | ja, Halbwertszeit 100 s |
| Ausrüstung daraus | nein |

## Herstellen

- 1 × [Bismut](../elemente/bismut.md) + 8 × [Nickel](../elemente/nickel.md) → 1 × [Roentgenium](../elemente/roentgenium.md) (Teilchenbeschleuniger, 600 s)
