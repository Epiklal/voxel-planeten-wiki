# Helium

![Helium](../bilder/elemente/helium.png)

Zuerst auf der Sonne entdeckt (1868, in ihrem Licht) – erst 27 Jahre später auf der Erde. Wird nie fest, egal wie kalt.

| Eigenschaft | Wert |
|---|---|
| Symbol | He |
| Ordnungszahl | 2 |
| Gruppe | Edelgas |
| Zustand (20 °C) | Gas |
| Dichte | 0 g/cm³ |
| Schmilzt bei | −272 °C |
| Radioaktiv | nein, stabil |

## Herstellen

- 10 × [Erdöl](../gegenstaende/erdoel.md) → 1 × [Helium](../elemente/helium.md) (Trennanlage, 20 s)

[Astat](../elemente/astat.md), [Mendelevium](../elemente/mendelevium.md), [Helium-Kühler](../gegenstaende/helium_kuehler.md)
