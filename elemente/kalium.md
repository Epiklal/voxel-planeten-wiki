# Kalium

![Kalium](../bilder/elemente/kalium.png)

Brennt auf Wasser mit violetter Flamme. Bananen sind leicht radioaktiv – wegen Kalium-40.

| Eigenschaft | Wert |
|---|---|
| Symbol | K |
| Ordnungszahl | 19 |
| Gruppe | Alkalimetall |
| Zustand (20 °C) | fest |
| Dichte | 0,862 g/cm³ |
| Schmilzt bei | 63 °C |
| Härte (Mohs) | 0,4 |
| Radioaktiv | nein, stabil |
| Ausrüstung daraus | ja |
| Im Wasser | Feuerkugel |

## Im Wasser

2 K + 2 H2O → 2 KOH + H2: Kalium wird so heiß, dass der Wasserstoff sofort mit lila Flamme brennt.

## Herstellen

- 2 × [Sylvin](../bloecke/sylvin.md) → 1 × [Kalium](../elemente/kalium.md) (Elektrolyseanlage, 8 s)
