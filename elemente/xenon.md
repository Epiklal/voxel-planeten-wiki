# Xenon

![Xenon](../bilder/elemente/xenon.png)

Ionentriebwerke von Raumsonden stoßen Xenon aus. Als Narkosegas lässt es fast ohne Nebenwirkungen schlafen.

| Eigenschaft | Wert |
|---|---|
| Symbol | Xe |
| Ordnungszahl | 54 |
| Gruppe | Edelgas |
| Zustand (20 °C) | Gas |
| Dichte | 0,006 g/cm³ |
| Schmilzt bei | −112 °C |
| Radioaktiv | nein, stabil |
