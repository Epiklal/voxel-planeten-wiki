# Palladium

![Palladium](../bilder/elemente/palladium.png)

Schluckt das 900-Fache seines Volumens an Wasserstoff, wie ein Schwamm.

| Eigenschaft | Wert |
|---|---|
| Symbol | Pd |
| Ordnungszahl | 46 |
| Gruppe | Übergangsmetall |
| Zustand (20 °C) | fest |
| Dichte | 12,023 g/cm³ |
| Schmilzt bei | 1555 °C |
| Härte (Mohs) | 4,8 |
| Radioaktiv | nein, stabil |
| Ausrüstung daraus | ja |

## Herstellen

- 1 × [Platinmetall-Konzentrat](../gegenstaende/platinmetall_konzentrat.md) → 1 × [Palladium](../elemente/palladium.md) (Trennanlage, 15 s)
