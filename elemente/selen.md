# Selen

![Selen](../bilder/elemente/selen.png)

Leitet Strom besser, wenn Licht darauf fällt – damit begannen Fotozellen und Kopierer.

| Eigenschaft | Wert |
|---|---|
| Symbol | Se |
| Ordnungszahl | 34 |
| Gruppe | Nichtmetall |
| Zustand (20 °C) | fest |
| Dichte | 4,81 g/cm³ |
| Schmilzt bei | 221 °C |
| Härte (Mohs) | 2 |
| Radioaktiv | nein, stabil |

## Herstellen

- 1 × [Anodenschlamm](../gegenstaende/anodenschlamm.md) + 1 × [Schwefelsäure](../gegenstaende/schwefelsaeure.md) → 1 × [Selen](../elemente/selen.md) (Chemiereaktor, 12 s)
