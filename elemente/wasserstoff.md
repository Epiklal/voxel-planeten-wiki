# Wasserstoff

![Wasserstoff](../bilder/elemente/wasserstoff.png)

Das häufigste Element im Universum. Die Sonne verschmilzt jede Sekunde 600 Millionen Tonnen davon zu Helium.

| Eigenschaft | Wert |
|---|---|
| Symbol | H |
| Ordnungszahl | 1 |
| Gruppe | Nichtmetall |
| Zustand (20 °C) | Gas |
| Dichte | 0 g/cm³ |
| Schmilzt bei | −259 °C |
| Radioaktiv | nein, stabil |

## Herstellen

- 1 × [Wasser](../bloecke/wasser.md) → 2 × [Wasserstoff](../elemente/wasserstoff.md) (Elektrolyseanlage, 4 s)
