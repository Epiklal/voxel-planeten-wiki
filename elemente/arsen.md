# Arsen

![Arsen](../bilder/elemente/arsen.png)

Das "Erbschaftspulver" – jahrhundertelang das beliebteste Gift. Heute in schnellen Halbleitern.

| Eigenschaft | Wert |
|---|---|
| Symbol | As |
| Ordnungszahl | 33 |
| Gruppe | Halbmetall |
| Zustand (20 °C) | fest |
| Dichte | 5,727 g/cm³ |
| Schmilzt bei | 614 °C |
| Härte (Mohs) | 3,5 |
| Radioaktiv | nein, stabil |
