# Rhenium

![Rhenium](../bilder/elemente/rhenium.png)

Das letzte stabile Element, das entdeckt wurde (1925). Hält Turbinenschaufeln in Düsentriebwerken heiß fest.

| Eigenschaft | Wert |
|---|---|
| Symbol | Re |
| Ordnungszahl | 75 |
| Gruppe | Übergangsmetall |
| Zustand (20 °C) | fest |
| Dichte | 21,02 g/cm³ |
| Schmilzt bei | 3186 °C |
| Härte (Mohs) | 7 |
| Radioaktiv | nein, stabil |
| Ausrüstung daraus | ja |

## Herstellen

- 8 × [Molybdänglanz](../bloecke/molybdaenglanz.md) → 1 × [Rhenium](../elemente/rhenium.md) (Trennanlage, 40 s)
