# Bismut

![Bismut](../bilder/elemente/bismut.png)

Wächst zu regenbogenfarbenen Treppenkristallen. Eigentlich radioaktiv – mit einer Halbwertszeit von 20 Milliarden Milliarden Jahren.

| Eigenschaft | Wert |
|---|---|
| Symbol | Bi |
| Ordnungszahl | 83 |
| Gruppe | Metall |
| Zustand (20 °C) | fest |
| Dichte | 9,78 g/cm³ |
| Schmilzt bei | 272 °C |
| Härte (Mohs) | 2,2 |
| Radioaktiv | nein, stabil |
| Ausrüstung daraus | ja |

## Herstellen

- 1 × [Bismuthinit](../bloecke/bismuthinit.md) → 1 × [Bismut](../elemente/bismut.md) (Ofen, 5 s)
