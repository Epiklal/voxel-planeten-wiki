# Bohrium

![Bohrium](../bilder/elemente/bohrium.png)

Nach Niels Bohr – entdeckt in Darmstadt.

| Eigenschaft | Wert |
|---|---|
| Symbol | Bh |
| Ordnungszahl | 107 |
| Gruppe | Übergangsmetall |
| Zustand (20 °C) | fest |
| Dichte | 37,1 g/cm³ |
| Schmilzt bei | −273 °C |
| Radioaktiv | ja, Halbwertszeit 61 s |
| Ausrüstung daraus | nein |

## Herstellen

- 1 × [Bismut](../elemente/bismut.md) + 8 × [Chrom](../elemente/chrom.md) → 1 × [Bohrium](../elemente/bohrium.md) (Teilchenbeschleuniger, 480 s)
