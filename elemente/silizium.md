# Silizium

![Silizium](../bilder/elemente/silizium.png)

Sand ist Siliziumdioxid – nach Sauerstoff das häufigste Element der Erdkruste. Aus reinem Silizium sind alle Computerchips.

| Eigenschaft | Wert |
|---|---|
| Symbol | Si |
| Ordnungszahl | 14 |
| Gruppe | Halbmetall |
| Zustand (20 °C) | fest |
| Dichte | 2,329 g/cm³ |
| Schmilzt bei | 1414 °C |
| Härte (Mohs) | 6,5 |
| Radioaktiv | nein, stabil |

## Herstellen

- 2 × [Quarzkristall](../gegenstaende/quarzkristall.md) + 2 × [Kohle](../gegenstaende/kohle.md) → 1 × [Silizium](../elemente/silizium.md) (Induktionsofen, 10 s)

## Verwendet für

[Magnesium](../elemente/magnesium.md), [Siliziumwafer](../gegenstaende/siliziumwafer.md), [Siliziumcarbid](../gegenstaende/siliziumcarbid.md)
