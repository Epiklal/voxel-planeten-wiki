# Tellur

![Tellur](../bilder/elemente/tellur.png)

Wer ein wenig davon einatmet, riecht wochenlang nach Knoblauch.

| Eigenschaft | Wert |
|---|---|
| Symbol | Te |
| Ordnungszahl | 52 |
| Gruppe | Halbmetall |
| Zustand (20 °C) | fest |
| Dichte | 6,24 g/cm³ |
| Schmilzt bei | 450 °C |
| Härte (Mohs) | 2,2 |
| Radioaktiv | nein, stabil |

## Herstellen

- 2 × [Anodenschlamm](../gegenstaende/anodenschlamm.md) + 1 × [Salzsäure](../gegenstaende/salzsaeure.md) → 1 × [Tellur](../elemente/tellur.md) (Chemiereaktor, 15 s)
