# Strontium

![Strontium](../bilder/elemente/strontium.png)

Färbt Feuerwerk leuchtend rot. Strontium aus Atombombentests fand man einst in Milchzähnen.

| Eigenschaft | Wert |
|---|---|
| Symbol | Sr |
| Ordnungszahl | 38 |
| Gruppe | Erdalkalimetall |
| Zustand (20 °C) | fest |
| Dichte | 2,64 g/cm³ |
| Schmilzt bei | 777 °C |
| Härte (Mohs) | 1,5 |
| Radioaktiv | nein, stabil |
| Ausrüstung daraus | ja |
| Im Wasser | sprudelt |

## Im Wasser

Sr + 2 H2O → Sr(OH)2 + H2: Strontium sprudelt heftig – im Feuerwerk färbt es rot.

## Herstellen

- 2 × [Coelestin](../bloecke/coelestin.md) + 1 × [Salzsäure](../gegenstaende/salzsaeure.md) → 1 × [Strontium](../elemente/strontium.md) (Elektrolyseanlage, 10 s)
