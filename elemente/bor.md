# Bor

![Bor](../bilder/elemente/bor.png)

Fast so hart wie Diamant. Bor schluckt Neutronen – damit regelt man Kernreaktoren.

| Eigenschaft | Wert |
|---|---|
| Symbol | B |
| Ordnungszahl | 5 |
| Gruppe | Halbmetall |
| Zustand (20 °C) | fest |
| Dichte | 2,34 g/cm³ |
| Schmilzt bei | 2076 °C |
| Härte (Mohs) | 9,5 |
| Radioaktiv | nein, stabil |

## Herstellen

- 2 × [Borax](../bloecke/borax.md) + 1 × [Magnesium](../elemente/magnesium.md) → 1 × [Bor](../elemente/bor.md) (Chemiereaktor, 12 s)

## Verwendet für

[Lawrencium](../elemente/lawrencium.md), [Kubisches Bornitrid](../gegenstaende/kubisches_bornitrid.md)
