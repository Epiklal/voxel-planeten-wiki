# Seaborgium

![Seaborgium](../bilder/elemente/seaborgium.png)

Das erste Element, das nach einem noch lebenden Menschen benannt wurde: Glenn Seaborg.

| Eigenschaft | Wert |
|---|---|
| Symbol | Sg |
| Ordnungszahl | 106 |
| Gruppe | Übergangsmetall |
| Zustand (20 °C) | fest |
| Dichte | 35 g/cm³ |
| Schmilzt bei | −273 °C |
| Radioaktiv | ja, Halbwertszeit 840 s |
| Ausrüstung daraus | nein |

## Herstellen

- 1 × [Californium](../elemente/californium.md) + 8 × [Sauerstoff](../elemente/sauerstoff.md) → 1 × [Seaborgium](../elemente/seaborgium.md) (Teilchenbeschleuniger, 420 s)
