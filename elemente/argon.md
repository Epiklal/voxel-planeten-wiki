# Argon

![Argon](../bilder/elemente/argon.png)

Fast 1 % der Luft, mehr als zwanzigmal so viel wie CO₂. "Argon" heißt "der Träge": Es reagiert mit nichts.

| Eigenschaft | Wert |
|---|---|
| Symbol | Ar |
| Ordnungszahl | 18 |
| Gruppe | Edelgas |
| Zustand (20 °C) | Gas |
| Dichte | 0,002 g/cm³ |
| Schmilzt bei | −189 °C |
| Radioaktiv | nein, stabil |

## Herstellen

-  → 1 × [Argon](../elemente/argon.md) (Luftzerlegungsanlage, 8 s)
