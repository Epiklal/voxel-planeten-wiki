# Francium

![Francium](../bilder/elemente/francium.png)

Kein Mensch hat je einen Brocken davon gesehen: Es zerfällt in Minuten. Auf der ganzen Erde gibt es nur rund 30 Gramm.

| Eigenschaft | Wert |
|---|---|
| Symbol | Fr |
| Ordnungszahl | 87 |
| Gruppe | Alkalimetall |
| Zustand (20 °C) | fest |
| Dichte | 1,87 g/cm³ |
| Schmilzt bei | 27 °C |
| Härte (Mohs) | 0,2 |
| Radioaktiv | ja, Halbwertszeit 1320 s |
| Ausrüstung daraus | nein |
| Im Wasser | explodiert |

## Im Wasser

Francium hat noch niemand in sichtbarer Menge gesehen – es müsste am heftigsten von allen reagieren. Hier: so.

## Herstellen

- 4 × [Goldbarren](../elemente/goldbarren.md) + 4 × [Sauerstoff](../elemente/sauerstoff.md) → 1 × [Francium](../elemente/francium.md) (Teilchenbeschleuniger, 180 s)
