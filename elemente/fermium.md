# Fermium

![Fermium](../bilder/elemente/fermium.png)

Auch aus dem Staub der Bombe. Das schwerste Element, das sich mit Neutronen herstellen lässt.

| Eigenschaft | Wert |
|---|---|
| Symbol | Fm |
| Ordnungszahl | 100 |
| Gruppe | Actinoid |
| Zustand (20 °C) | fest |
| Dichte | 9,7 g/cm³ |
| Schmilzt bei | 1527 °C |
| Radioaktiv | ja, Halbwertszeit 100 Tage |
| Ausrüstung daraus | nein |

## Herstellen

- 4 × [Einsteinium](../elemente/einsteinium.md) + 3 × [Uranbrennstab](../gegenstaende/uranbrennstab.md) → 1 × [Fermium](../elemente/fermium.md) (Forschungsreaktor, 400 s)
