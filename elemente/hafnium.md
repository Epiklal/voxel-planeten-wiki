# Hafnium

![Hafnium](../bilder/elemente/hafnium.png)

Steckt in jedem Zirconium und lässt sich kaum davon trennen – schluckt aber Neutronen 600-mal stärker: Steuerstäbe in U-Booten.

| Eigenschaft | Wert |
|---|---|
| Symbol | Hf |
| Ordnungszahl | 72 |
| Gruppe | Übergangsmetall |
| Zustand (20 °C) | fest |
| Dichte | 13,31 g/cm³ |
| Schmilzt bei | 2233 °C |
| Härte (Mohs) | 5,5 |
| Radioaktiv | nein, stabil |
| Ausrüstung daraus | ja |

## Herstellen

- 8 × [Zirconium](../elemente/zirconium.md) → 1 × [Hafnium](../elemente/hafnium.md) (Trennanlage, 30 s)
